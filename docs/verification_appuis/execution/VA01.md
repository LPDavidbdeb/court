# VA01 — Instantané du constat

Verdict : **BLOQUÉ** pour la livraison sur données réelles ; recette synthétique réussie.

## Critère et exécution

Le générateur conserve les textes, occurrences, ordre, numéros imprimés issus
de la table de concordance, liens et identités des cotes. La sérialisation est
déterministe et accompagnée de SHA256SUMS. Un instantané différent ne peut pas
écraser un instantané existant.

La fixture SQLite contient trois énoncés et quatre liens ; le premier porte
43 dans le Markdown et 41 dans la concordance imprimée. Deux générations sont
comparées octet pour octet. Des cas supplémentaires vérifient le refus d'un
appariement ambigu, d'un écrasement et d'une lecture réelle sans accord.

À la suite de la [revue d'exécution](../REVUE_EXECUTION.md), deux tests
supplémentaires éprouvent le contrôle croisé : un numéro stocké `41`, conforme
au numéro imprimé, est accepté malgré le numéro Markdown `43` ; un numéro
stocké `43` est refusé et le message identifie l'énoncé `1`.

Commande : `python3 -W error::ResourceWarning -m unittest legal.verification_appuis.tests.test_va01 -v`

Sorties réelles : [Python système](VA01.tests.txt) et
[Python du .venv](VA01.venv.tests.txt). Les **5 tests passent** avec chacun des
deux interpréteurs, avertissements ResourceWarning traités comme erreurs.
